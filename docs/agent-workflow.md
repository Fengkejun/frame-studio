# 灵感创作 Agent

## 用户操作

桌面应用默认进入「灵感创作」。先打开「模型设置」，选择已有文本连接，配置视频服务、模型、密钥及每次媒体预算预留上限。需要自动生成首帧时启用图片工具；也可以直接上传角色参考图。

输入一句需求后点击「开始自动制作」。Agent 会用文本模型规划制作步骤、选择已启用技能，生成剧本和分镜，再调用已配置的视频工具。图生模式自动使用上传的参考图，或在有图片模型时先生成首帧；文生模式直接编排连续分镜提示词。参考图以缩略图传给导演模型，理解图中角色需要文本连接具备视觉能力。

例如：

> 创作一部12秒的治愈动漫。白发蓝眼的少女邮差在雨夜屋顶给橘白猫送信，信纸化成星光小伞。保持人物、服装、画风和天气一致，自动完成剧本、分镜和视频。

用户只要求剧本时，自动模式可选择仅编剧和分镜；也可明确切换到「先写剧本与分镜」，该模式禁止提交图片或视频生成。结果展开即可查看，视频自动保存到本机、可播放和另存 MP4。继续输入修改要求会携带上一版剧本及分镜，新项目和素材保留原作品。未发送的文字在切换模型页面后保留。

继续修改时，规划、剧本和分镜三步使用同一份上一版作品快照；只说“修改结尾”也会携带原有内容。分镜同时接收本轮最新剧本。原项目缺失时会停止并提示，不会在缺少原稿的情况下直接重写。

「高级画布」用于查看真实节点产物、编辑分镜、字幕、配音和时间线。普通创作流程无需手动搭节点或逐个确认生成版本；Agent 会自动选择本次生成的首个可用版本并记录选择。

## 执行与恢复

- 模型返回结构化工具计划，原生执行器校验工具依赖、模型能力、时长及合计媒体预留预算，随后调用现有真实工具。工具集合目前为编剧、分镜、图片生成、视频生成及文件检查；技能不会自行获得新的模型接口或命令执行能力。
- 对话、计划、工具事件、关联项目和媒体任务号存入 SQLite。切换页面或刷新不会停止后台制作。
- 真正重启应用后，文本请求标记待核实；有已保存视频任务号的会话可继续查询原任务，不会重新 POST。没有任务号的未知提交保留记录，需要核对服务商结果。
- 查询原视频任务不重新读取技能文档，也不改变当时记录的技能列表；技能停用、修改或移走后，仍可恢复已有视频的查询和下载。
- 停止结束本地自动执行与视频查询，已提交的远程生成可能继续。图片同步接口仍可能在服务端完成，原有图片任务记录保留。
- 分镜的小量时长舍入误差在生成后校正；计划明显超时或预算不足会在媒体提交前停止。下载的视频会读取实际尺寸、时长，显著短于计划的版本提示审看，保留候选并停止自动后续步骤。
- 本地预算按既有预估/预留规则限制提交，实际扣费取决于服务商，文本费用另计。

## 本地技能

默认带有「动漫编剧」「角色与场景连续性」「连续分镜导演」三项技能，保存为应用数据目录下 `agent/skills/<id>/SKILL.md` 与 `manifest.json`。Agent 根据当前需求选择并加载全文，剧本和分镜请求中包含实际技能内容。

「技能库」支持启停、输入公开 GitHub 仓库及关键词搜索技能、下载到本机。默认搜索 `fal-ai-community/skills`，支持中文「分镜」「视频」等映射。网络下载以 Git blob SHA 定位文件，保存来源和 SHA-256 指纹，调用前检查内容。导演判断需要新知识且自动搜索已开启时，也可搜索和安装相关文档技能；网络失败时继续使用本机技能。

目前集成的是 **文档技能**：下载 `SKILL.md`，将创作方法提供给模型，由内置工具完成媒体操作。依赖平台专用脚本、外部程序或额外模型的技能，需要单独适配后才能执行相应能力。技能与对话目前属于本机配置，现有项目包迁移工作流和素材，不包含整套 Agent 配置与会话。

接口及格式依据：[GitHub Git Trees](https://docs.github.com/en/rest/git/trees)、[Git Blobs](https://docs.github.com/en/rest/git/blobs)、[Agent Skills 文档格式](https://github.com/vercel-labs/agent-skills/blob/main/AGENTS.md)。视觉输入协议依据 [Ollama 原生图像输入](https://docs.ollama.com/capabilities/vision) 与 [OpenAI 兼容输入](https://docs.ollama.com/api/openai-compatibility)。

## 当前能力范围

当前自动制作交付一条模型允许时长内的短片，模型单次上限仍为15秒。需要更长故事时，可先生成完整剧本和第一段视频，界面会明确标注范围；整部长片的自动延展、跨段衔接、独立配音混音和自动视觉审片尚未纳入这条 Agent 执行链路。角色与动作一致性仍需播放审看。

## 验证

`npm run test:agent` 使用真实桌面 IPC、本地导演模型及图片/视频协议服务，检查模型规划、技能全文进入请求、剧本和分镜持久化、文生与图生、自动首帧、原声视频保存播放、继续修改、页面刷新、真正退出后重启恢复、预算预检和未知提交不重试。测试媒体由本地工具生成，不代表云端 AI 出片质量。`npm test` 覆盖浏览器预览的原生能力禁用与原有界面，`npm run test:desktop` 覆盖已有媒体制作流程。
