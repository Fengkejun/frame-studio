# 框架边界与下一阶段入口

## 当前结构

`src/app/App.tsx` 负责应用壳与工作台、工作流、模型连接、设置页面的切换。页面很少，暂用类型化的本地页面状态；需要项目 URL、深链接或前进后退时再引入路由。

功能代码按 `features` 组织；跨功能的 UI、IPC、类型放在 `shared`。工作流功能把 React Flow 的画布状态、Rust 的持久化状态和运行状态分开，模型 SDK 通过原生适配器隔离。

`src/shared/lib/desktop.ts` 提供桌面环境检测与环境信息调用；工作流和媒体 IPC 分别集中在 `workflow/api.ts` 与 `workflow/mediaApi.ts`。`get_app_info` 对应 `src-tauri/src/commands/mod.rs`，类型在 `shared/types/desktop.ts`。浏览器预览不调用 Rust；桌面模式才发起真实 IPC。超时只结束前端等待，不意味着取消原生命令。

## 安全与持久化

- Tauri `build.rs` 显式声明命令清单，`capabilities/main.json` 只允许主窗口调用已登记的项目、文本任务和媒体命令，不授予原始文件系统或 Shell 权限。
- 使用系统原生标题栏；不开放自定义窗口控制权限。
- 生产页面不允许任意远程脚本、远程连接和内嵌页面。开发模式单独允许固定 Vite 地址与热更新 WebSocket。
- 桌面主题偏好使用 localStorage；浏览器预览也用它保存工作流图。原生项目和媒体元数据保存于 SQLite。
- 模型密钥不能放入 `VITE_*`、前端源代码、localStorage 或普通项目 JSON；当前由 Rust 通过系统凭据库读写。

## 工作流第一阶段（已实现）

`features/workflow` 提供可保存的节点画布、项目切换、撤销/重做、JSON 导入导出、结构化输出校验和运行记录。文本节点是创作需求、故事编剧、分镜导演与提示词助手；图片节点接收分镜并汇集已确认的首帧版本，视频节点汇集与当前首帧对应的已选片段，成片节点汇集时间线导出的 MP4。

工作流数据在 TypeScript 与 Rust 两侧都做边界校验：节点数量、连线类型、环路、输入大小、镜头 ID、镜头数量和总时长都会在执行前检查。浏览器预览使用 localStorage 保存图结构，但不会伪造原生运行成功；桌面端使用应用数据目录中的 SQLite 保存项目和运行快照。

模型连接目前支持 Ollama 本地 API 和 OpenAI Chat Completions 兼容文本服务。API Key 通过 Rust 原生层写入系统凭据库，工作流 JSON 只保存连接 ID，不保存密钥。服务地址要求云端 HTTPS，本机服务才允许 HTTP；响应大小和请求超时有上限，提交结果无法确认时不会自动重复请求。

运行引擎按 DAG 顺序执行，保存每个节点的状态和结构化产物。应用退出后，未能确认的文本请求会标为“结果待核实”，不会静默重发；取消只停止本地调度和等待，服务端是否继续生成由服务本身决定。

## 分镜首帧阶段（已实现）

`workflow/mediaApi.ts`、`useMedia.ts` 和 `ImageStudio.tsx` 提供分镜对应的生图、素材选择和任务记录。Rust `workflow/media.rs` 负责不可变图片版本与首帧绑定，`media/comfy.rs` 负责本机 ComfyUI 的提交、轮询及恢复，`media/cloud.rs` 负责 OpenAI Images API。图片写入应用数据目录；SQLite 记录元数据，不把 base64 媒体放进图结构。

首帧绑定包括项目、节点、分镜产物版本和镜头 ID。文本产物更新后，旧图片继续保留但不自动继承选择。图片节点接入文本 DAG，但只读取明确选中的版本并校验原图仍存在；缺少首帧时运行状态为“等待首帧”，用户选择后可单独重跑图片节点。整图重新生成分镜时，图片节点会等待新版本的首帧选择，不会自动启动生图或产生额外生图费用。云端图片 API Key 仅保存在系统凭据库，提交结果无法确认时标记未知且不自动重发。具体恢复和数据备份约定见 [首帧工作流](image-workflow.md)。

## 镜头视频阶段（已实现）

VideoStudio.tsx 与 media/video.rs 提供 Wan 2.7 图生视频的单镜头提交、持久化远程任务 ID、轮询、下载、版本选择与恢复。视频任务独立于图片和文本调度，最多同时查询 3 个任务；未知结果不自动重发。视频节点只汇集显式选中的版本，并核对源首帧，详见 [镜头视频工作流](video-workflow.md)。

## 成片合成阶段（已实现）

TimelineStudio.tsx 与 media/composition.rs 提供版本化时间线、镜头裁剪与排序、SRT/VTT 字幕、配音与音乐混合、本地 FFmpeg 导出。SQLite 保存草稿、音频资产和导出记录；成片节点在视频节点之后汇集已完成且与当前时间线相符的 MP4。可选的 Tauri sidecar 打包脚本为 Windows 安装包准备 FFmpeg/FFprobe。详见 [成片时间线](timeline-workflow.md)。

## 验证分层

- `npm run check`：前端类型、规范、格式。
- `npm test`：页面启动、浏览器降级、主题保存与系统主题响应、存储失败恢复。
- `desktop:check` / `desktop:lint`：原生代码与配置检查。
- 本机启动 Tauri 后看到真实版本、平台、架构，并能“重新检查连接”，才算完成原生 IPC 验证。

跨平台配置保留，但只应声称在实际构建和运行过的平台上验证通过。
