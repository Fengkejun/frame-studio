# 音频波形与配音时间对齐

## 操作

1. 在「时间线与导出」加入视频片段，选择配音和背景音乐。
2. 「音频波形与时间对齐」显示同一成片时间轴上的两条波形及片段位置。音乐短于成片时循环显示，音量调整也反映在波形高度上。
3. 用「配音起点」输入秒数，或拖动滑块，调整配音开始的位置。精度为 1 毫秒，起点须早于成片结束；「配音回到起点」重置为 0 秒。
4. 已应用的自动字幕随配音起点整体移动。校对框中的时间仍相对源配音；匹配当前配音的「下载 SRT」生成对齐后的字幕，超过成片结束的部分裁掉。
5. 导出 MP4：配音起点之前补静音，较短配音尾部补静音，较长配音在成片末尾截断。音乐独立从 0 秒循环播放。

「原始配音试听」播放原音频；成片中的延迟与混音效果需在导出的 MP4 中试听。导入 SRT/VTT 和片段字幕使用成片时间，不随配音偏移。

## 保存和兼容

起点保存在时间线草稿、导出任务快照与项目素材包内。旧草稿缺少起点时默认 0 秒；字幕原始版本和音频原件保持不变。项目包仍为版本 2，跨设备对齐时双方应使用支持此功能的应用版本。

波形由应用内 FFmpeg 在本机分析，不上传音频。分析使用 8 kHz 单声道 PCM，输出 512 个峰值，是音量概览，不是精确的多声道编辑或逐字时间标注。每份音频限制 20 MB、最长 1 小时，最多同时分析两份，单次超时 30 秒；前端最多缓存 12 份版本结果，关闭应用后清除。波形不写入项目包，恢复到新设备时重新分析。

未安装 FFmpeg 或原件丢失时显示原因；可使用含 FFmpeg 的 Windows/macOS 安装包，或修复原件后重试。波形分析失败不改变音频选择及字幕版本。

## 验证

- Rust 单元测试覆盖跨读取块的 PCM 样本、静音与峰值、字幕平移/裁剪/溢出、旧草稿默认值和素材包起点恢复。
- Windows 原生测试通过真实 IPC 分析「半秒静音 + 半秒音调」，验证 512 个峰值。
- 导出一个配音延迟 0.2 秒的 MP4，解码检查前段静音及后段非静音；检查字幕在 0.1 秒未出现、0.35 秒已经烧录，并验证原始字幕版本未变。
- 下载对齐 SRT、重新加载起点设置，以及调整起点时不再次提交语音生成或转写任务。

滤镜规则依据 [FFmpeg adelay、apad 与 atrim 文档](https://ffmpeg.org/ffmpeg-filters.html)。
