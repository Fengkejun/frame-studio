## 本机 Windows 编译限制

默认测试及发布编译多次出现 Rust 1.98.1 的 `0xc0000005`，曾同时出现 PDB 链接错误和 `0xc0000374` 堆损坏。应用事件日志指向 `rustc_driver` 或 `tauri_macros`。独立新构建目录也在未改动的 `windows` 依赖编译阶段复现；暂无足够证据确定更底层原因。

本机测试采用单个代码生成单元、优化级别 1、无调试符号编译测试程序，再执行全部 47 项。原生验收的调试程序使用同样的临时包编译参数，并开启 `tauri/custom-protocol` 内嵌前端。项目默认配置已恢复。

本轮新版 Windows 发布安装包未生成，旧 NSIS 文件不是本轮产物。可使用已通过原生验收的 `src-tauri/target/debug/frame-studio.exe` 运行本轮功能。调试符号备份及隔离构建证据保留于被忽略的 `artifacts/`，未删除原有构建目录。
