## 二、账户、服务端调用与计费（待开始）

先交付可本地验收的服务端闭环，再连接线上后台：

1. 账户登录、会话和用户资源隔离。
2. 服务端模型目录、版本化价格和生成前报价；上游密钥仅保留在服务端。
3. 钱包与不可变流水，金额使用整数；预算预留、结算和退回分别记录。
4. 请求幂等键、远程任务持久化、超时待核实状态、恢复查询和对账。
5. 桌面端连接平台账户、展示余额、报价、任务和费用记录。

验收：重复请求只创建一个任务、扣费一次；余额不足时不调用上游；跨用户访问被拒绝；结果待确认时保留预留并等待核实。实际零售价、上游计费和参考视频附加费通过明确配置与账单验证，不从宣传页自动推断。

## 三、支付与充值（待开始）

用户本轮暂不考虑后台服务器、域名及支付商户配置；本轮先完成媒体链路验收，不接入线上充值。

在第二阶段的钱包与流水验证完成后接入选定支付渠道：

1. 服务端创建充值订单，以服务端价格和币种为准。
2. 验证支付通知签名、订单、商户、金额、币种及支付状态。
3. 重复通知仅入账一次；处理通知延迟、主动查询、订单关闭与退款对账。
4. 桌面端展示充值入口和订单状态；支付成功以服务端核验为准。

线上接入需要部署地址、支付渠道及商户配置；对外收费前需确认上游转售条款。开发和测试阶段不开放真实充值入口。
