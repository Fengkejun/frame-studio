# 默认工作流

首次启动没有项目时，会创建七节点、六连线的动漫短片模板：

```text
创作需求 → 故事编剧 → 分镜导演 → 提示词助手
                           ↘ 图片节点 → 视频节点 → 成片节点
```

模板提供《星光来信》示例需求，默认三个镜头、总计十二秒。文本节点需要选择本机有效的文本模型连接。图片、视频和成片节点汇集用户明确选择的资产版本，不在启动时提交付费任务。

桌面应用启动后直接进入工作流。项目上方可以创建「完整模板」，也可以用「新建工作流」继续从基础节点开始编辑。选择项目并点击「设为默认工作流」后，下次启动恢复该项目；其他项目更新不会改变默认选择。默认项目 ID 保存在本机数据库，浏览器预览使用独立偏好存储。

更新应用保留现有项目，不会自动改写旧画布或修补用户有意保留的节点。使用完整模板可以从已连接的流程开始，再把合适的项目设为默认。

视频服务地址、型号、生成方式、地区和分辨率会记住；提示词、镜头和首帧引用仍按当前镜头生成，密钥仍保存在系统凭据库。历史远程任务保留原请求参数，查询恢复不应用新的默认设置。

验证覆盖完整模板的合法连线、默认选择与较新项目并存、重启恢复、原项目保留、偏好存储不可用时的错误处理，以及原生桌面首次启动。设备配置前的数据库备份和本机检测结果保存在被 Git 忽略的 `artifacts/device-setup-2026-10-16/`。
