# 首次使用与连接检查

桌面应用打开后，工作台显示四步准备清单。各环节可以独立配置，暂时不用的视频服务不会阻止文本创作。

首次打开时清单展开；可手动收起，之后仍可从工作台展开或刷新状态。收起偏好只保存在本机，不影响项目数据。

1. **故事与分镜**：在「模型连接」保存 Ollama 或 OpenAI 兼容文本服务、模型 ID 与所需密钥。回到工作台点击「检测模型」，应用读取服务的模型列表并核对 ID，不发起生成。
2. **首帧生成**：在「首帧与素材」设置本机 ComfyUI，或保存云端图片密钥。工作台的「检测 ComfyUI」读取已保存的地址（尚未生成过图片时使用 `http://127.0.0.1:8188`），列出 checkpoint 数量。云端密钥只显示是否已保存，不将它当作服务权限验证。
3. **镜头视频**：在「镜头视频」按地区保存服务密钥。工作台区分「密钥已保存」与实际服务验证；发起镜头任务前仍须确认账户权限与费用。
4. **本机导出**：工作台自动检测 FFmpeg、FFprobe、H.264/AAC 编码器和字幕滤镜。可点击「刷新准备状态」复查。完整 Windows 安装包包含这些工具；开发运行时也可从系统 PATH 查找。

连接检测不会提交图片或视频生成任务。文本列表检查不保证模型能产出符合工作流要求的 JSON；ComfyUI 的 checkpoint 列表检查不保证当前模板与模型架构兼容。本机工具检查不代替一次实际 MP4 导出。浏览器预览只展示引导，不运行原生检测。

相关操作：[首帧工作流](image-workflow.md)、[镜头视频](video-workflow.md)、[成片时间线](timeline-workflow.md)。
