# 图片批量队列

在「首帧与素材」中配置云端图片或本机 ComfyUI，再展开「批量生成镜头候选」。勾选 1–24 个当前有效分镜镜头，点击「提交批量图片队列」。每个镜头使用分镜中的 `imagePrompt`；模型、尺寸、候选数、参考图、种子和其他参数沿用表单设置。生成完成后仍需比较并选择候选，批量提交不改变已选首帧。视频批量属于下一阶段。

## 调度与预算

全应用同时运行一个批量图片队列，按镜头顺序提交。图片任务忙碌时等待；已知失败不阻止后续镜头生成。云端表单显示合计预算预留，创建前检查总预留，每项提交时还会执行项目预算校验。其他任务期间消耗预算时，后续项可能被拦截。

未提交项尚未计入已提交任务的累计预留。预留不等于最终扣费；失败、未知结果和手动跳过的已提交请求仍保留预算记录。

## 暂停与恢复

- 「暂停队列」阻止后续提交，已进入提交的当前请求继续；不远程取消请求或停止 ComfyUI 服务。
- 「继续队列」先检查当前结果，再处理剩余镜头，已完成项不会重发。ComfyUI 已有 `prompt_id` 时恢复原任务查询。
- 已知失败可点击「重排失败项（可能计费）」，获得新任务 ID 并保留旧 ID；点击继续队列才重新提交。
- 提交结果未知时暂停并禁用继续。核对服务商任务和用量后，可点击「已核对，跳过未知项」继续其他镜头；未知项不自动重发。

## 保存与验证

SQLite schema 9 新增 `image_batches`，保存请求快照、顺序、子任务 ID、重跑历史、状态和候选引用，不保存密钥。每项调用适配器前保存提交意图和预分配任务 ID。重启后队列暂停，已有结果按子任务记录恢复；提交意图存在但子任务记录缺失时标记未知，避免重复计费。

队列和生成任务历史留在原设备，不随 `.framepack` 迁移；生成图片与首帧选择可迁移。

原生测试使用固定 PNG 和本机云端/ComfyUI 协议服务，覆盖顺序、预算、暂停与页面重载、失败重跑、未知结果处理、ComfyUI 原任务查询恢复及首帧选择保持，不执行真实 AI 推理。Rust 测试覆盖数据库升级及重启恢复。
