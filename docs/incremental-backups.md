# 增量备份与恢复

在桌面版「工作流画布」中展开「项目备份与恢复」，选择一个应用数据目录之外的文件夹，然后点击「备份当前项目」。应用先保存画布，再备份项目及其素材版本。可用的备份记录按时间排列，并显示素材大小、本次新增大小和复用大小。

## 保存内容

范围与 [项目素材包](project-bundles.md) 一致：画布和节点输出、该项目的图片与缩略图、视频、音频、自动字幕、角色参考图和首帧绑定、视频选择、时间线草稿、磁盘上仍存在的成功成片及封面。

API Key、模型连接、Ollama/ComfyUI 模型文件、文本运行历史、生成任务、预算设置和回收区素材保留在原设备。无项目上下文且未绑定的素材不属于当前项目备份。

## 素材复用

选定位置下会创建 `FrameStudioBackups` 文件夹：

```text
FrameStudioBackups/
  repository.json       # 格式标记，版本 1
  objects/              # 按文件内容校验值保存的共享素材
  snapshots/            # 各备份点的完整项目清单
```

每次备份都会读取源素材并计算 SHA-256。已存在的相同内容经校验后直接复用，仅写入新素材与新的项目清单。相同内容的不同素材版本仍保留各自的元数据和引用关系。复用大小按项目逻辑文件统计，可能包含同一备份内的重复内容；清单本身的少量大小不包含在素材大小中。

每个备份点包含完整清单，恢复时不依赖前一个备份点。迁移或另存备份时，请复制整个 `FrameStudioBackups` 文件夹；在新设备选择它的上一级目录。共享素材目录应一并保留。

备份只有在素材复制、同步和校验完成后才发布记录。失败或中断的临时清单不会显示为成功备份；已经复制的共享素材可在后续备份中复用。应用不会自动删除旧备份或共享素材。备份未加密，保存位置由用户管理。

## 恢复为新项目

选择备份记录后点击「恢复为新项目」。应用先保存当前画布，校验备份清单与全部素材，再新建名称带「恢复副本」的项目，并自动切换到该项目。

项目 ID、素材版本 ID 和成片 ID 会重新生成，首帧、角色、视频、音频、字幕父版本和时间线引用一并迁移。原项目及其文件保持原样。恢复后的成片和封面保存到应用数据目录的 `exports` 子目录，原设备绝对路径不会复用。

可以多次恢复同一记录，得到彼此独立的副本。恢复后的节点连接为空；再次运行 Agent 前，请重新选择模型连接。

## 校验与限制

- 单个素材上限为 4 GB；单个清单上限为 16 MB、10,000 个逻辑文件。
- 校验失败、文件缺失、目录指向异常或清单引用不完整时，恢复会中止；当前项目保留。
- 异常清单会在列表中跳过并显示提示，其他可用记录仍可选择。列表读取只校验清单，素材字节校验发生在备份复用和恢复时。
- 应用内同时只执行一个备份操作；媒体生成、配音、转写、文本运行或导出正在执行时，请待完成后再备份或恢复。
- 当前为手动备份，不包含定时备份、备份保留策略、跨设备云同步或磁盘加密。
- 恢复普通操作错误时会回滚数据库并清理已移动文件；强制终止进程后的文件清理遵循现有项目包机制，暂未增加崩溃恢复日志。

## 验证

Rust 回归测试覆盖重复备份、同一备份内的内容复用、新增素材、删除中间清单后恢复、同机重复恢复、完整媒体引用迁移、损坏文件、路径与清单异常、目录保护。

浏览器界面测试覆盖选择位置取消、备份前保存画布、操作中禁用按钮、恢复失败保留项目和成功切换副本。`npm run test:desktop` 通过隔离测试目录验证真实 Rust 命令、媒体文件和界面恢复；不调用收费云端模型。
