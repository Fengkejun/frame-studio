# 本机模型选择建议

核对日期：2026-10-16。资料为用户提供的[羊村 API 模型广场](https://site.whyapi.top/pricing)、配音 curl，以及当前视频中转站 Key 的真实 `/v1/models` 响应。网页公开列表显示 144 个模型；本机这枚 Key 实际列出 24 个，不能把公开列表等同于本账户权限。下列名称是中转站模型 ID，不代表厂商官方产品命名或能力保证。

| 用途                       | 本项目当前可配置                                               | 说明                                                                                                                                                         |
| -------------------------- | -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 中文剧本、分镜、提示词     | 现有 Vectio `grok-4.7`                                         | 已验证实际文本回复，默认项目的三个文本节点均绑定该连接。                                                                                                     |
| 云端首帧、角色参考与图生图 | `gpt-image-2`、`gpt-image-2.5-flare`、`gpt-image-2.5-sunburst` | 当前图片适配器已支持；这三个 ID 出现在所查 Key 目录中。是否拥有实际出图、编辑权限仍以生成结果为准。                                                          |
| 首帧图生视频               | `grok-imagine-video-1.5-lite`                                  | 当前软件已有适配，且此 Key 目录列出该型号。已知接口为 `/v1/videos`，可选择文生或首帧模式。                                                                   |
| 文生视频                   | `minimax-h3`                                                   | 软件已有 `/v2/video_generation` 适配，目录列出该型号；使用已核对的能力范围。                                                                                 |
| AI 配音                    | `mai-voice-2.1`                                                | 用户 curl 明确为 `/v1/audio/speech`，`voice: en-US-Harper`，返回 MP3；本轮补充自定义音色与 MP3 选项。Harper 示例为英文音色 ID，中文音色需服务商给出准确 ID。 |
| 自动字幕                   | 尚需转写服务                                                   | 当前 Key 目录未列出 Whisper / transcription 型号。软件支持兼容转写服务及带时间戳的分段结果，也可导入 SRT / VTT。                                             |
| 本地文本                   | Ollama `qwen2.5-coder:7b`                                      | 本机服务已启动，但实际已安装模型列表为空；云端文本可独立使用。                                                                                               |

文本服务与媒体服务分别配置地址和凭据，语音模型应填在「时间线与导出 → AI 配音生成」，不作为编剧节点的文本模型。

## 可考虑的后续扩展

- **动漫图片**：公开页面列出 `acgn_image`，描述为动漫专用文生图、返回 base64，且不支持编辑。适合研究角色概念图；当前图片下拉框尚未开放这个 ID，需要补参数约束与对应适配。角色图生图仍可沿用现有图片适配器。
- **其他云端图片**：本 Key 还列出 `gpt-image-2.5`、`recraft-v4.1-flash`、`grok-imagine-image-2.0`、`seedream-5.0-pro`、`muse-image-1.0`、`flux-3-image`。需要各型号的生成与编辑 curl，核对尺寸、参考图和输出结构后再加入。云端 `flux-3-image` 与本机 ComfyUI 的 FLUX.1 流程分别处理。
- **更多配音**：目录列出 `mai-voice-2.1-flash`、`gemini-3.8-flash-lite-tts`、`gemini-3.8-flash-tts`。作为候选，先核对接口、音色和语言；目录出现不等于与当前语音请求完全兼容。
- **视频增强**：`proteus`、`starlight-precise-2.6` 适合后续成片增强研究，需要输入视频的接口示例和独立处理步骤，不能直接作为当前首帧生成型号选择。
- **其他视频**：目录列出的 `heygen-video-1`、`wonder-3.5` 尚未进入本项目的型号能力表，需要生成和查询 curl、首帧字段及参数范围后适配。
- **SD 型号**：目录列出 `sd2.0-933-*`、`sd2.0-903-*` 别名，当前标准 `sd2.0-mini` 未出现在这枚 Key 的目录。已有 SD 适配保留，但本机默认先选择目录明确列出的 Grok 视频。不要把未核对的别名按相同参数硬套。
- **其他文本模型**：公开页列出 Claude Sonnet / Opus 系列及 OpenAI 兼容入口，可作为创作候选；本机这枚媒体 Key 未列出这些文本型号。需开通对应分组，再通过模型目录和实际回复两项检测。

## 尚需提供的信息

1. MAI 中文配音音色 ID 或中文配音示例。
2. 自动字幕所用转写服务的地址、模型、密钥，以及是否返回分段时间戳。
3. 如要增加上表外的图片、视频或增强型号，提供其完整 curl（省略密钥）与参数范围。

模型目录检测不会提交付费媒体生成。本机配置、运行版本、真实检测结果以应用和 `artifacts/device-setup-2026-10-16/` 中的本次报告为准。
