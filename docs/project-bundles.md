# 项目包与跨设备恢复

在桌面版「工作流画布」中，先保存当前项目，再点击「导出项目包」。应用生成单个 `.framepack` 文件。另一台设备安装 Frame Studio 后，点击「导入项目包」选择该文件，恢复完成后自动切换到该项目。

项目包包含工作流画布及输出、图片原图和缩略图、视频片段、音频素材、镜头首帧与角色参考图绑定、视频选择、时间线草稿，以及仍存在于磁盘上的成功导出 MP4 和封面。恢复后的 MP4 和封面放在应用数据目录的 `exports` 子目录中；原设备的绝对路径不会写入项目包或新设备的项目记录。单个文件上限为 4 GB。

模型服务配置、API Key、Ollama/ComfyUI 模型文件、生成任务和文本运行历史不会随项目包迁移。导入后的节点保留已有输出，但模型连接 ID 会清空；再次运行节点前，需在新设备选择模型连接。仍可使用素材和时间线继续编辑、预览及重新导出。

导入保留项目与素材版本 ID，以维持引用关系。如果目标设备已有同 ID 项目或素材，应用会拒绝恢复并保留原数据。需要恢复备份时，请使用尚未包含该项目的设备或应用数据目录。应用会校验包内每个文件的 SHA-256；校验失败、素材缺失或项目包不完整时，不会写入项目数据库。

旧的「导入 / 导出」按钮只处理画布 JSON，不包含媒体文件。跨设备迁移请使用「项目包」按钮。
