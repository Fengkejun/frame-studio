# SD 系列视频生成

在「镜头视频 → 视频服务」选择「视频中转站」，根地址使用 `https://api.wulusai.com`。模型提供 `sd2.0`、`sd2.0-fast`、`sd2.0-mini`、`sd2.5` 四个 ID，沿用该服务根地址保存的密钥。中转站展示描述为「满血不卡933」；请求只发送模型 ID。

## 参数

- 支持文生视频与当前镜头的单首帧图生视频。
- 时长为 4–15 秒整数。
- 分辨率必须选择：480P / 720P / 1080P / 4K，请求发送小写值。
- 比例可选 adaptive、16:9、4:3、1:1、3:4、9:16、21:9；不选时省略 `ratio`。
- `sd2.5` 首帧模式只允许 adaptive。界面切换模式时清理其他比例；不选时使用服务默认的 adaptive，后端也会在提交前校验。
- 文生视频必须填写提示词，SD 首帧模式允许留空。存在负面提示词时作为文字内容一并传入。

先为镜头确认首帧。文生模式只发送文字，该首帧用于镜头关联和候选封面；首帧模式发送所选图片的 JPEG data URL，保留原图版本。下载后读取实际视频时长、尺寸和帧率。

## Ark 入口

两条等价入口中，本次选择 Ark：

```text
POST /api/v3/contents/generations/tasks
GET  /api/v3/contents/generations/tasks/{id}
```

文生请求把文字放在 `content` 的 `text` 项，首帧请求增加：

```json
{
  "type": "image_url",
  "image_url": { "url": "data:image/jpeg;base64,..." },
  "role": "first_frame"
}
```

请求包含整数 `duration` 和必填 `resolution`。比例未选时省略；不发送 tools、回调地址或其他未配置字段。完成状态为 `succeeded`，从响应的 `content.video_url` 读取成片地址；缺少地址时保留原任务供继续查询，不拼接下载地址，也不重新提交生成。

路径、模型 ID、时长、分辨率及收费说明依据用户提供的中转站契约。图片对象、首帧 role 和 data URL 格式参考 [Ark 创建视频任务文档](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)。上游文档不代表第三方中转站已通过真实调用验收。

## 预算与范围

当前提供文生和单首帧模式。首尾帧、多参考图、参考视频、参考音频和工具选项尚未提供输入界面，不会作为隐藏参数发送。

预算由用户手动预留，计入本地项目上限；不自动估算服务账单。后续支持参考视频时，需使用有参考成片单价，并加上参考视频精确秒数乘附加单价，不对参考时长取整，也不使用最低时长折算。本次没有参考视频输入，也未实现该收费计算。

## 验证范围

Rust 测试覆盖四个模型的路径、字段、响应地址、时长/分辨率边界、首帧提示词可选、SD 2.5 adaptive 限制，以及省略未选参数。浏览器测试覆盖四个型号的选项、4K、模式切换与比例清理。

Windows 原生测试使用本机固定 MP4 协议服务，验证四个型号文生提交、SD 2.5 首帧、缺少成片地址后的原任务恢复及素材入库。4K 在此指请求参数验证，不代表真实服务已生成 4K 媒体。

本次不调用付费 SD 生成。真实出片质量、输出尺寸、账户权限及账单需在真实服务验收中确认。
