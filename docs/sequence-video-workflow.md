# 整段分镜生成与连续性整改

## 为什么之前三段视频像三个不同作品

逐镜头模式分别发起生成，模型各自重新解释人物和场景。提示词写“角色一致”只是文字要求；缺少相同视觉参考和连续上下文时，可能出现人物换脸、二维变写实、雨夜变雪景。拼接只能修复顺序、画幅和声音时间，解决不了源视频的角色漂移。

## 新的默认路径

创作需求 → 故事 → 分镜 → 整段视频 → 成片。另保留提示词助手分支。

1. 展开画布上方「全片统一设定」，填写画风、固定角色外观、场景天气和连续性要求。这些内容会进入后续文本 Agent、图片及视频提示词，已有素材保留。
2. 生成并审核分镜，确认镜头顺序及总时长。12 秒可以编排为 3 个 4 秒镜头。
3. 「镜头视频 → 整段分镜生成」把所有镜头编排成带时间段的同一条提示词。文生模式无需为每个镜头生成首帧；首帧图生模式只使用第一个镜头已确认的首帧。
4. 核对视频服务、模型、总时长与预算，点击「一次提交整段分镜」。一次操作只产生一个远程任务；未知结果保持原有的查询恢复和防重复扣费规则。
5. 播放候选，审看人物、场景、道具、动作因果和切镜。选择整段版本后，视频节点收集一个覆盖全组分镜的视频，时间线装配时排除该视频覆盖的其他短镜头。
6. 「保存原始 MP4（含原声）」保存模型原始视频及声音，不转码、不重新生成，已有目标文件会要求换一个文件名。需要自己的字幕、配音和音乐时再进入时间线；时间线音轨仍来自另设的配音和音乐。

新创建的默认模板是 6 节点、5 连接，分镜直接连接视频节点。旧项目保留节点和素材，可以继续逐镜头制作；需要完整画布路径时，将视频节点的图片输入改接到分镜节点即可。此连接只汇集已确认视频，不发起云端生成。

## 真实边界

- 当前适配的模型单次上限为 15 秒，具体最短时长按模型约束。整段时长必须等于分镜总时长，超限会在提交前阻止，既不截短也不自动拆成多次付费请求。
- 时间分镜是提示词，不是严格剪辑控制。模型可能偏离切镜时间或忽略部分动作，必须审片。
- 一次生成可减少独立任务造成的漂移，并不保证角色外观绝对一致。需要固定造型时应使用已确认首帧，仍需检查结果。
- 原生服务的一致性参考、关键帧、视频延展能力与中转站接口是不同协议；目前没有把原生延展接口假定为中转站已有能力。更长作品仍需要适配服务商实际支持的延展或带连续性参考的分段协议。
