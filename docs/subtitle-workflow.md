# 配音自动字幕

## 操作路径

1. 打开「工作流 → 时间线与导出」，加入视频片段。
2. 在「画面与声音」选择一份已导入或生成的配音，可先试听。
3. 打开「配音自动字幕 → 字幕识别服务」，填写 OpenAI 兼容转写服务的 `/v1` 根地址、模型 ID 和密钥。默认模型是 `whisper-1`；其他模型须返回兼容的分段时间戳。
4. 「检查转写服务」只读取模型目录，不上传配音，也不验证实际转写权限。填写本次预算预留金额和项目预算上限后，点击「发送当前配音并生成字幕」。这一步会将当前音频上传给所选服务，并可能产生服务费用。
5. 在识别记录中点击「校对字幕」，或选择「字幕版本预览」。调整每段文字、开始和结束时间；支持添加、删除片段。
6. 修改后点击「保存字幕新版本」。原始识别版本保持不变，新版本记录父版本和配音来源。
7. 点击「应用字幕到时间线」，随后导出 MP4。也可「下载 SRT」，供其他剪辑软件使用。生成和保存都不会自动替换已应用字幕。

## 时间与素材规则

- 编辑时间相对源配音。可在 [音频波形与时间对齐](audio-alignment-workflow.md) 调整配音起点；匹配当前配音的自动字幕在 MP4 和 SRT 下载时整体后移，并在成片结束处裁掉。源字幕版本保持不变，逐字高亮尚未实现。
- 字幕按顺序排列，片段互不重叠，起点小于终点，终点不超过源配音时长。
- 每份字幕 1–1000 段，每段最多 1000 字，SRT 总大小最多 100 KB。文本使用单行纯文本，不接受字幕标签和格式控制符。
- 成片长度由视频片段决定，较长的配音和字幕在成片结束处截断。请在导出前校对视频和配音长度。
- 自动字幕绑定具体配音版本。更换或取消配音后，应用提示来源不匹配并暂停该字幕的导出；重新选择匹配配音、应用另一字幕版本，或点击「改用片段字幕」即可继续。
- 原有片段字幕和导入 SRT/VTT 继续可用。导入文件会解除自动字幕绑定。
- 转写上传支持 WAV、MP3、M4A、FLAC、OGG，音频最多 20 MB。AAC 可参与混音，但转写时需导入上述格式。

## 请求与恢复

请求使用 `POST /v1/audio/transcriptions`，以 multipart 上传文件，并要求 `response_format=verbose_json`、`timestamp_granularities[]=segment`。服务须返回 `segments[].start/end/text`；应用不会从旁白文本推算字幕时间。OpenAI 的时间戳能力见[官方语音转文本文档](https://developers.openai.com/api/docs/guides/speech-to-text)。

转写密钥按服务地址独立保存在 Windows/macOS/Linux 系统凭据库，不写入 localStorage、工作流或项目包。非密钥设置可在本机保存。

每次提交先记录预算预留和任务，再发送请求。预留金额由用户依据服务商价格填写，只是本机计划额度；失败和结果待核实的提交仍计入预留，不代替服务商账单。

同一应用同时执行一个转写任务。HTTP 拒绝记为失败；连接中断、缺少时间戳、响应异常或超过 2 MB 记为结果待核实。没有可查询的远端任务 ID，因此应用重启只恢复已保存的字幕结果，其余标记待核实，不自动重发。请核对服务商用量后再手动提交。

数据库升级到版本 8，保留旧配音、时间线和导出数据。项目包版本 2 包含字幕、配音来源和父版本引用，不包含转写任务与密钥；新版应用兼容旧版本 1 项目包。恢复版本 2 项目包时，两台设备均应安装支持自动字幕的版本。

## 验证范围

`cargo test --locked --lib` 覆盖时间戳与字幕边界、源配音校验、预算计入、数据库升级、任务恢复和字幕项目包恢复。

`npm run test:desktop` 使用隔离的 Windows 数据目录、固定 WAV 和本地转写协议服务，运行真实 Tauri IPC、系统凭据库与 FFmpeg。检查上传确为所选配音、校对不覆盖旧版本、显式应用、换配音/篡改字幕拦截、失败和未知结果、预算拦截、重新加载不重发，以及 MP4 中实际出现字幕。

这类协议测试不执行云端 AI 识别；真实服务的识别质量、语言表现、权限和费用需要有效的转写服务配置单独验收。Windows 安装包、macOS ARM64/Intel 安装包继续沿用现有打包流程。
