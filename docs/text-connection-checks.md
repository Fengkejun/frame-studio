# 文本模型连接检测

在「模型连接」填写名称、接入方式、API 根地址、模型 ID 和密钥后，可以直接点击检测按钮；程序会先保存当前配置，不再要求额外点击保存才开放检测。密钥仍保存在系统凭据库。

- **测试连接**：读取 Ollama `/api/tags` 或兼容 OpenAI 服务的 `/v1/models`，检查认证与模型目录，并显示耗时、当前模型和地址。不发起文本生成。
- **测试模型回复**：向配置的模型发送一次极短文本，验证实际聊天协议和非空文本响应；可能产生少量费用。Ollama 首次加载模型可能较慢。超时或断线后不会自动重试。

目录中缺少模型不等于实际调用失败，可进一步使用回复测试；目录检测通过也不等于模型一定具备生成权限。HTTP 401/403 提示认证或权限问题，429 提示限流或额度问题；空回复和无效聊天格式不会被显示为成功。
