# 镜头转场与音频淡入淡出

## 使用

在「时间线与导出 → 镜头转场与音频淡入淡出」选择效果：

- **直接切换**：旧时间线默认行为，不重叠镜头。
- **交叉溶解**：前一镜头逐渐淡出、后一镜头逐渐淡入。
- **经黑场切换**：转场中间经过黑场。

同一时间线的所有相邻镜头共用转场设置。转场时长为 0.1–2 秒，不超过任一裁剪后片段时长的一半，避免连续转场互相重叠。单镜头时不产生转场。

转场会重叠素材并缩短成片。输出按 30 fps 帧边界统一计算：每段裁剪时长向上取整为完整帧，转场时长取最近的完整帧；总帧数 = 片段帧数总和 − 转场帧数 ×（片段数 − 1）。例如三个各 1.2 秒的镜头，加两次 0.3 秒转场，输出为 3 秒。时间线、字幕与波形使用该帧时钟，避免多镜头累积取整偏差。

片段字幕在转场中点切换，避免两段字幕同时出现。自动转写字幕仍绑定配音并随配音起点移动，按新的成片终点裁剪；导入 SRT/VTT 使用原文件的成片时间，需自行核对剪辑后的对应关系。波形、起点范围、字幕下载和成片节点使用缩短后的时间轴。

音乐、配音分别设置淡入及淡出时长，0 秒关闭，单项最多 10 秒：

- 音乐从成片起点淡入，在成片末尾淡出；短音乐继续循环。
- 配音从设置的配音起点淡入，在原配音结束或成片截断处淡出，以较早的时间为准。
- 同一轨道的淡入、淡出总时长不超过它在成片中的播放长度。更改裁剪、转场或配音后，超出范围时会提示调整并暂停导出。
- 波形高度反映音量与淡化包络。原始音频试听保持源文件内容，混音后的效果需试听导出的 MP4。

## 保存与验证

效果保存在时间线、导出快照与项目素材包内。旧草稿缺少 `effects` 时默认直接切换、无淡化，原素材保持不变。项目包仍为版本 2，迁移时双方使用支持这些效果的应用版本。

需要 FFmpeg 的 `xfade`、`afade` 和 `adelay` 滤镜，工具检测与 Mac 最终 DMG 检查均核对这些能力。

Rust 单元测试覆盖三镜头起止时刻、转场限制、字幕中点切换、配音实际尾部、旧草稿默认值及素材包恢复。Windows 原生测试通过本地视频协议服务保存三份真实可解码的红、蓝、绿视频版本，经应用界面选择并导出：检查两次溶解的混合像素、黑场中间帧、3 秒成片时长、配音起点与两条音轨的淡化 RMS、参数拦截和设置重载。测试使用固定素材，不执行云端 AI 推理。

滤镜依据：[FFmpeg xfade 与 afade 文档](https://ffmpeg.org/ffmpeg-filters.html)。
