## Windows 构建

Rust 1.98.1 在本机继续出现 `0xc0000005` 编译器崩溃。单个代码生成单元、优化级别 1 的调试构建也曾失败；改用仅应用包优化级别 0 后成功。构建参数仅通过命令传入，项目默认配置未修改。

当前原生验收使用 `src-tauri/target/debug/frame-studio.exe`，编译时启用 `tauri/custom-protocol` 内嵌新版前端。测试程序使用单代码生成单元、优化级别 0、无调试符号执行全部 47 项测试。本记录不将旧 NSIS 文件计为本轮新版安装包。
