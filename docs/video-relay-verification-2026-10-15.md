# 视频中转站验证（2026-10-15）

## 实际生成

Windows 桌面应用通过真实 Rust IPC 提交 `grok-imagine-video-1.5-lite` 首帧任务：1 秒、480P，使用本机红纸船湖面图片。服务认证通过且模型列出。

首次对象格式的 `input_reference` 被 HTTP 400 明确拒绝，未返回任务 ID。依据服务错误改为 base64 data URL 字符串后取得远程任务 ID。随后仅查询该 ID，没有重新提交生成。首次查询的 `unknown` 稍后变为 `in_progress` 和 `completed`，真实地址位于 `metadata.url`。

应用重启后找回原任务，下载并保存不可变视频版本；桌面「镜头视频」候选播放器实际播放成功。
