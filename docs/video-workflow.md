# 镜头视频工作流

除下述阿里云万相之外，也可选择 [视频中转站](video-relay.md)，使用 MiniMax 文生视频或 Grok 文生/首帧图生视频。各模型的时长、分辨率、预算预留和密钥配置见该说明。

## 使用步骤

1. 桌面应用中先生成分镜，在「首帧与素材」为镜头明确选择首帧。
2. 打开「镜头视频」，选择镜头和服务地区，保存对应地区的阿里云百炼 API Key。可点击「检查连接」读取该地区模型目录；认证通过及模型列出不保证实际生成权限或额度，也不产生生成费用。
3. 核对视频提示词、2–15 秒时长、720P / 1080P 分辨率及本次标价预估，可设置项目云端媒体预算上限，再点击「提交图生视频任务」。每次提交都可能产生服务商费用。
4. 等待任务完成，播放候选并点击「选为镜头片段」。重新生成保留旧版本和原选择。
   也可点击「导入本地视频」，在系统文件对话框中选择 H.264 MP4。文件复制到素材库后关联当前镜头和首帧，仍需手动选为片段；导入不提交云端请求。
5. 画布连接「分镜 → 图片节点 → 视频节点」。图片节点汇集首帧；视频节点汇集已选片段。缺少片段时显示「等待片段」。这些汇集操作不提交付费生成请求。

当前适配器使用 Wan 2.7 `wan2.7-i2v-2026-04-25`，支持北京、新加坡地区；模型权限与密钥地区需匹配。首帧宽高为 240–8000 像素，宽高比为 1:8–8:1，发送前转为 RGB JPEG，编码后上限 20 MB。

视频预估按 [阿里云模型价格表](https://www.alibabacloud.com/help/en/model-studio/model-pricing) 中 `wan2.7-i2v-2026-04-25` 的地区与分辨率每秒速率乘以时长计算（标价核对日期：2026-09-28）。北京 720P / 1080P 分别为 $0.086012 / $0.143353 每秒，新加坡分别为 $0.10 / $0.15 每秒。优惠、免费额度和实际扣费以服务商账单为准。提交时的预估额连同图片的手动预留额计入项目预算；超过上限的本地提交会被阻止。失败及结果未知的请求仍占用本地预算记录，旧任务未计入。该预算不是服务商硬性扣费上限。

## 任务与恢复

多个镜头可以在表单中展开「批量生成视频候选」顺序提交，支持合计预算校验、暂停、原任务查询恢复和失败单项重跑。具体参数与恢复规则见[视频批量队列](video-batch-queue.md)。

- 提交一次后立即保存远程任务 ID，每 15 秒查询状态。最多同时查询 3 个任务，同一镜头同时执行 1 个任务；镜头之间的失败互不影响。
- 「停止本地查询」只停止本机等待，远程生成可能继续，费用由服务商决定。
- 有远程任务 ID 的任务在查询/下载失败或应用重启后可点击「继续查询原任务」。恢复只查询和下载，不再次提交。
- 提交响应丢失且未获得任务 ID 时显示「结果未知」，不会自动重试；先核对服务商任务和用量。
- 远程状态 UNKNOWN 也记录为「结果未知」。服务商任务 ID 与下载链接通常保留 24 小时，建议生成后及时保存。
- 更换首帧后，旧视频仍可播放，但需要以当前首帧重新生成并选择视频；视频节点校验首帧版本对应关系。
- 重新生成分镜会产生新的分镜产物 ID，旧片段继续保留，不自动绑定到新分镜。

## 存储与边界

SQLite schema 5 新增视频任务、视频版本、镜头选择表。应用数据目录 `assets/` 保存 MP4；任务记录保存参数、远程 ID 和源首帧版本。API Key 按地区保存在系统凭据库，不进入数据库或画布 JSON。

云端下载流写入临时文件，完成后检查 MP4 容器及 FFprobe 视频信息，原子改名后保存记录；云端下载上限仍为 256 MB。本地导入支持 H.264 MP4，最大 2 GB、时长 0.1 秒至 1 小时、宽高不超过 8192；暂未提供其他编码的自动转换。导入通过原生文件对话框读取，文件内容不经前端内存传递。无视频流、错误编码、损坏或复制失败时清理临时文件，不改变原有片段选择。

候选显示实际视频时长、编码尺寸与帧率；生成请求的时长与分辨率仍保留在任务记录。旧素材首次播放时读取并保存实际信息。内嵌预览使用单文件授权的 Tauri asset protocol，支持按需读取和拖动播放，不再使用整文件 base64 或 64 MB 预览上限。候选封面仍使用关联首帧，本地导入标明来源与原文件名。

加入时间线时使用实际时长，每次最多添加前 60 秒，之后可调整裁剪起止；完整素材保留。视频原音保存在素材中供预览播放，当前成片音轨由时间线选择的配音与背景音乐生成。

每个项目显示最近 100 条任务和 500 个视频版本。完整备份需在退出应用后复制整个应用数据目录。画布 JSON 只保存资产引用；[跨设备项目包](project-bundles.md) 包含导入视频、实际媒体信息和片段选择。视频片段的排序、裁剪、字幕、音轨和 MP4 导出见 [成片时间线](timeline-workflow.md)。

## 验证

`npm run test:desktop` 在隔离数据库、凭据与 WebView2 目录中调用真实 Rust IPC。localhost Wan 协议服务返回固定 H.264 MP4，覆盖提交参数、鉴权头、远程 ID 轮询、下载入库、实际播放、显式选择、视频节点等待与汇集、失败后保留选择、暂停后页面重载恢复、远程过期及提交响应丢失。恢复断言不会再次 POST。Rust 测试覆盖应用重启时已知/未知任务恢复和数据库迁移。

这些测试不执行云端 AI 推理。真实生成质量、账户权限、地区可用性和实际费用需使用有效密钥验收。

## 接口依据

- [阿里云 Wan 2.7 图生视频 API](https://www.alibabacloud.com/help/en/model-studio/image-to-video-general-api-reference)：异步提交、任务查询、首帧格式与地区配置。
- [FFprobe 文档](https://ffmpeg.org/ffprobe.html)：读取视频流时长、尺寸、编码和帧率。
- [Tauri asset protocol](https://v2.tauri.app/security/asset-protocol/)：动态授权单个本地素材文件供播放器加载。

截至 2026-09-24，OpenAI 官方视频参考页说明 Sora API 于该日停用，因此本阶段使用 Wan 适配器。参见 [OpenAI 视频接口](https://developers.openai.com/api/reference/resources/videos/methods/create)。
