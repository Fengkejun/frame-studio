# AI 配音生成

## 使用流程

1. 在工作流中打开「时间线与导出」，找到「AI 配音生成」。
2. 展开「语音服务设置」，填入 OpenAI 兼容语音服务的 `/v1` 根地址和模型 ID，例如 `gpt-4o-mini-tts`。云端使用 HTTPS，本机服务可使用 HTTP。
3. 保存该服务的 API Key。密钥只进入系统凭据库，按服务地址隔离；图片、文本与语音密钥独立管理。
4. 「检查语音服务」只读取模型目录，不生成音频，也不证明账户具有语音生成权限。
5. 输入最多 4096 字的旁白，或点击「使用时间线字幕」。应用按所选模型获取音色目录，选择目录中的音色、WAV / MP3 格式及 0.25–4 倍语速。切换模型或地址会清空旧选择；目录读取失败、尚未选择或已过期时先刷新，生成按钮保持禁用。
6. 按服务商报价填写本次预算预留金额，点击「生成配音」。默认预留值仅为可修改的表单初值，并非官方价格。图片、视频和配音共同计入本项目的云端媒体预算；超限时在提交之前拦截。
7. 生成后点击「试听音频」，再点击「用作配音」。新版本不会自动替换时间线已有配音。生成的声音为 AI 合成声音。
8. 导出 MP4 时，所选配音与背景音乐通过本机 FFmpeg 混合为 AAC。音频按时间线长度裁切或补静音；目前需要手动调整镜头长度，没有逐句自动对齐。

## 接口与恢复

使用 `POST /v1/audio/speech`，发送 `model`、`input`、`voice` 和 `response_format`（`wav` 或 `mp3`），读取非流式音频响应。只有语速不是默认 1 倍时才发送 `speed`。新任务必须使用当前模型目录内的音色；未适配目录的自定义模型先接入目录适配器。既有音频和任务记录保留。

## 按模型加载官方音色目录

- `mai-voice-2.1` / `mai-voice-2.1-flash`：联网读取[微软 MAI 官方音色表](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/mai-voices)，解析语言和性别，中文音色优先显示。包含 `zh-CN-Bo`、`zh-CN-Grant`、`zh-CN-Harper`、`zh-CN-Lan`、`zh-CN-Mei`、`zh-CN-Wei`。目录请求不发送中转站密钥，不会生成音频或收费。
- OpenAI TTS：按适配型号加载官方文档音色表快照，界面明确显示核对日期 2026-10-16，不将其称为实时账户权限列表。
- 官方支持不等于中转站已经开放。列表展示来源；当前中转站有真实成功记录的是 `en-US-Harper` + MP3，包括用户的中文旁白。其他音色尚未逐个进行真实收费验收。
- 目录与服务地址、模型绑定，有效期 15 分钟。生成前 Rust 再次验证目录、模型、音色和有效期，验证失败在创建任务和预留预算之前拦截。目录标识不发送给语音服务，不含凭据，应用重启后重新读取。
- 读取失败、空目录、未知模型或旧请求迟到时不沿用别的模型列表。点击「刷新音色列表」可重新读取。暂未提供风格参数，避免把不支持的 style 发给中转站。

用户提供的中转站示例：根地址 `https://api.wulusai.com/v1`、模型 `mai-voice-2.1`、音色 `en-US-Harper`、格式 MP3。中转站请求使用原始音色 ID；微软直接 SSML 接口中的模型后缀不拼入此中转站的 voice 字段。模型目录中出现该型号只证明目录检测通过，实际语音结果需单独验证。

响应最多 20 MB，连接和请求均有超时，不跟随重定向。保存前检查对应 WAV / MP3 文件头，再以 FFprobe 验证可解码音频流；不把 JSON 文件链接当音频保存。原件先写临时文件，验证后改名，再写入素材记录。每次生成有独立版本 ID，既有文件不被覆盖。旧任务缺少格式字段时继续按 WAV 读取。

SQLite schema 7 新增配音任务表，保存旁白、模型、参数、预算预留及结果，不保存密钥。明确的非成功 HTTP 响应记为失败；连接中断、无效音频、超大响应或本地保存中断记为「结果待核实」。此时保留预算记录，由用户核对服务商用量后决定是否手动生成新版本。没有自动重试或远程取消。

应用退出后，若任务对应音频版本已入库且原件仍在，会找回该版本；其他未完成任务标记为「结果待核实」，不重复提交。已生成音频和时间线配音选择可随 [项目素材包](project-bundles.md) 迁移，服务密钥及生成任务历史不进入包。

## 验证范围

Rust 测试覆盖请求边界、格式兼容、预算累计、schema 6 升级和重启恢复。浏览器测试验证原生功能禁用及损坏偏好恢复。Windows `test:desktop` 通过隔离凭据和本地语音协议服务返回固定 WAV / MP3，验证真实 Rust IPC、自定义音色与请求参数、鉴权、音频试听解码、显式版本选择、失败和未知结果、超大响应、密钥隔离、预算拦截及配音参与真实 MP4 导出。

协议测试使用固定音频，不执行云端语音模型推理。2026-10-16 另以用户提供的中转站真实调用一次 `mai-voice-2.1`，使用 `en-US-Harper` 和 MP3，成功保存并在桌面应用解码播放 1.872 秒英文音频。该结果不代表中文音色已经验收；中文音色 ID、读音和实际计费仍需分别核对。

接口依据：[OpenAI Speech API](https://developers.openai.com/api/reference/resources/audio/subresources/speech)。
