# WhyAPI 动漫 Agent 选型与首轮测试参数

核对日期：2026-10-17。依据[模型广场](https://site.whyapi.top/pricing)及其[公开计费接口](https://site.whyapi.top/api/pricing)，目录共 145 个模型，计费版本 `a42d372ccf0b5dd13ecf71203521f9d2`。

站内模型 ID、接口标记和价格只代表该服务的公开声明，不证明上游身份、当前账户权限、视觉能力或实际生成效果。以下选型依据用途、现有项目适配和公开价格，不是质量排名。本轮未提交模型推理、图片、视频或语音请求。

## 配置状态

已准备[测试参数模板](../config/whyapi-anime-test-presets.json)和[完整模型筛选快照](../config/whyapi-model-selection-2026-10-17.json)。快照保留全部 145 个 ID、用途分类、项目兼容状态、公开价格和分组。模板目前需要人工填写到应用，不是项目包，也不是一键导入格式。

当前设备访问 `https://site.whyapi.top` 时证书主机名校验失败；目录通过独立网页读取渠道取得。控制台实际 API 根地址尚未确认，所以没有替换用户现有连接或向该地址发送密钥。生成前须填入控制台确认、TLS 验证通过的地址；不要关闭证书校验。视频配置填写 API 服务根地址，文本、图片及语音填写其 OpenAI 兼容 `/v1` 地址，均不填写 `/pricing`。

在应用内分别保存文本、图片、视频、语音密钥。文本令牌需要选定文本分组权限，媒体模型需要 `workflow` 分组权限；是否可共用令牌须看账户设置，不能由公开目录确定。已有 Wulusai 密钥不会自动当作 WhyAPI 密钥使用。

## 导演、剧本、分镜与后续审片

首测导演选择 `gpt-6.1-sol`，备选 `grok-4.7`、`gemini-3.8-flash`、`claude-sonnet-4-6`；成本对照可选 `gpt-5.6-luna`、`gpt-6-luna`、`qwen3.8-flash`。这些 ID 均在站点目录中有聊天协议标记，具体分组和权限见快照。先用剧本模式测试有效结构化输出，再决定是否切换模型。`gpt-6-luna` 仅列在 `all_officia` 分组，不能假定默认令牌能调用。

完整快照另列出 67 个通用导演文本候选，覆盖 Claude、GPT、Gemini、Grok、DeepSeek、Qwen、GLM、Kimi、MiniMax、MiMo、Seed、Step、Hunyuan、LongCat、Muse 等目录型号。它们只是协议候选，不是都已通过 Agent JSON 或图像输入验收。代码专用、自动代码审查、匿名/免费别名及用途不明型号单列，不作为首测导演。

审片候选先复用导演模型，或单独验证 `gemini-3.8-flash`、`grok-4.7`、`deepseek-v4-flash-vision-exp` 的读图能力。聊天接口存在不代表可读取图片或视频；需先验证图像输入，再接入实际抽帧审片。目前 Agent 没有自动视觉审片步骤。

当前 Agent 固定规划温度 0.3、剧本/分镜温度 0.4、`stream=false`、文本请求超时 180 秒。无需另填不存在的采样或推理参数。文本费用按分组、输入输出和缓存计算，不能只看单一倍率；本地媒体预算不包含文本费用。

- `suno-v6` 是未适配的配乐候选，站点列价每次 0.52 USD、两首。不能通过现有普通文本或语音工具直接当作音乐文件处理。

## 测试顺序与验收

1. 确认API地址和令牌分组，在「模型连接」保存独立的 WhyAPI 文本连接，先检查真实回复。随后在「Agent模型设置」选择该连接、视频中转站、模型与预留额，再保存图片密钥。模板 `providerId` 必须替换成应用实际保存的文本连接ID。
2. 先选「先写剧本与分镜」，使用模板的同一目标，检查人物设定、两镜头顺序及8秒总时长。文本仍计费。
3. 新建创作，切回自动模式，输入模板中明确要求“先生成首帧再图生”的目标。确认实际计划包含生成首帧；当前配置中的 `mode` 不强制覆盖模型计划，因此需看计划和事件记录。
4. 仅执行一条8秒视频，检查保存的原任务号、文件实际时长、画面连续性、角色及雨夜设定。出现结果待核实时先查询原任务并核对账单，不自动重发。
5. 基础视频通过后，再在时间线生成短配音、试听、装配字幕与导出。自动审片和语音合成尚未加入这条Agent链路，不应把原声视频保存当作已完成独立配音混音。
6. 对照模型时每轮只更换一个环节，保留提示词和其他参数，分别记录耗时、实际价格、JSON有效率、人物一致性和播放结果。不要一次对目录全部模型批量发起收费请求。
